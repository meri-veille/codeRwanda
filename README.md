# CODERWANDA WebApp Project

## Project Overview

The **CODERWANDA WebApp** is a simple, modern, and responsive web application designed to provide users with an attractive landing page and easy access to registration and login pages.

The project was developed using HTML and CSS, with a clean purple, white, and light-blue color theme.

## Features

- **Modern Homepage:** An attractive landing page introducing the application.
- **User Registration:** A registration form where users can enter their full name, email, password, and confirm their password.
- **User Login:** A login form where existing users can enter their email and password.
- **Responsive Design:** Pages are designed to adapt to different screen sizes, including desktop, tablet, and mobile.
- **Easy Navigation:** Users can navigate between the homepage, registration page, and login page.
- **Modern Styling:** Clean layouts, attractive buttons, cards, and gradient backgrounds.

## Technologies Used

- **HTML5:** Used to structure the web pages.
- **CSS3:** Used to style the pages, create layouts, and make the application responsive.
- **Git:** Used for version control and tracking project changes.
- **GitHub:** Used to host and manage the project repository.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder on your computer.
3. Locate the `index.html` file.
4. Double-click `index.html` to open it in your web browser.
5. Navigate through the homepage, registration page, and login page.

You can also open the project using Visual Studio Code and use the Live Server extension.

## Installation and Setup

To clone the repository, run:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project folder:

```bash
cd CODERWANDA-WebApp
```

Open the folder in Visual Studio Code:

```bash
code .
```
